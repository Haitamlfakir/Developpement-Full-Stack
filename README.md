# 🎓 Full Stack – Filière Presentation

A responsive web application built with **React.js** to present the Développement Full Stack training program. The application provides information about the training, learning objectives, modules, technologies, career opportunities, and admission process.

## 🚀 Features

- **Program Presentation:** Introduction to the Full Stack development training.
- **Sidebar Navigation:** Navigate between sections with smooth scrolling.
- **Training Modules:** Display modules organized by academic year.
- **Technologies:** Showcase the technologies taught during the program.
- **Career Opportunities:** Present potential professional opportunities.
- **Authentication Modal:** Login and registration interfaces.
- **Form Validation:** Validate user inputs and display error messages.
- **Responsive Design:** Adapted to desktop, tablet, and mobile screens.
- **Interactive UI:** React state management using `useState`.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Haitamlfakir/Developpement-Full-Stack.git
```

### 2. Navigate to the project directory

```bash
cd fullstack-page
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```
